# 时序关系推断：方法、实现与验收

更新：2026-11-16。本文保留离线研究实现与历史验收记录。关系推测的网页入口、采集与推断 Web 接口已移除，不再属于在线产品功能。

## 当前问题定义

输入是每位已采集作者截至指定年份的论文集合，而非只含中心学者的论文。输出是给定候选范围内的主要指导关系排序，以及由联合最优关系组成的候选谱系。关系、同门和跨代链均保留论文证据；它们不是学位或任职记录。

依据 [Wang et al., KDD 2010, Mining Advisor-Advisee Relationships from Research Publication Networks](https://hanj.cs.illinois.edu/pdf/kdd10_cwang.pdf)，采用有时间约束的因子模型。当前实现复用其局部统计量和联合目标，用整数优化替换论文的近似消息传递。下述明确约定不是原作者已经验证的通用常数，也不把本项目称为原论文实验的精确复现。

## 从论文到局部证据

对学生候选 i 与导师候选 j，在年份 t 累计各自论文数 A、B 及共同论文数 C：

- Kulczynski：K = C(1/A + 1/B)/2。
- 有方向的不平衡率：IR = (B-A)/(A+B-C)。
- 区间内局部势函数：mean((K+IR)/2)，截断至数值安全范围；它不是经校准的师生概率。

使用原论文的严格发表起点排序和 R3（必须跨至少两个共同发表年份）。如果共同论文数超过任一方完整历史中的论文数，则记录历史不一致并排除该边，不让数据缺失提高分数。

YEAR2 在实现中明确为：选取使 Kulczynski 前后两段均值差最大的边界，第一段至少覆盖两个共同发表年份；没有观察到下降时，标记结束未观测。此定义解决原论文文字说明不足以唯一指定代码的问题。模型区间不能称作毕业年。

## 联合约束与精确求解

每个人选择一个主要导师候选，或选择“导师不在观察范围内”。若同时选择 A→B 与 B→C，则 B 的受指导区间必须结束于 B→C 模型区间开始之前。这是原模型的实质假设；同时受指导与指导他人的情形可能不符合它。

每个候选状态对应一个二进制变量 x，最大化 sum(log(local_potential) × x)：

1. 每个人所有状态的 x 之和为 1。
2. 不相容的两个状态满足 x₁+x₂≤1。
3. 未知导师状态的势函数显式设为 0.5，写入每次结果，不藏在代码分支中。

使用 SciPy/HiGHS 求解每个连通分量的最优联合配置，再固定每个候选状态重求条件最优值，得到 max-marginal 排序。它是最大值而不是对其余状态求和，因此不能把归一化后的分数称作后验概率。只接受求解器确认最优的结果；超时明确返回未完成，不把临时可行解冒充已完成排序。

模型计算相容的主要导师 MAP 森林。只有通过身份识别验收的版本才能将其作为关系候选图显示；当前版本未通过，因此不生成师生身份标签及其衍生同门、跨代图。数值排序和联合选择仍保留在审计证据和导出中，它们是待检验的替代假设。实际多导师识别需要另行验证允许多个并存指导状态的模型，不能偷偷改变本模型含义。

## 工程闭环

- `scholartrace/tpfg.py`：年度证据、局部势函数、约束构造、分量求解与条件最优排序。
- `scholartrace/inference.py`：整条推断链先应用截止年，再计算关系和模式。
- `scholartrace/server.py`：完成缓存可无 Key 重算；旧方法结果返回需要重算，保留原始论文。
- 历史网页曾提供截止年、全部作者对的排序审计、模型参数、真实验收结果和原论文链接；详细年度证据及未知导师分数保存在 JSON 导出中。截止年同时限制采集候选池的形成和关系特征计算。
- 主流程已删除 GMM 及分量到“导师”标签的人工映射；没有并列保留两套生产推断逻辑。
- 页面及在线计算均删除无真实标签支撑的变点到学位推断路径。现有离线训练工具仍可用于明确标注任务，但不会自动加载到在线主流程或生成学历身份。

## 验证与可重复性

数学验证用独立的完整枚举核对多路径 DAG 上的条件最优值，覆盖冲突链、孤立人物、同年起点和预算耗尽。接口验证覆盖截止年、缓存无 Key 重算和旧结果失效。测试夹具用于验证数学与工程正确性，不用于报告现实准确率。

真实数据采用 [Ke et al. (2022), Scientific Data](https://doi.org/10.1038/s41597-022-01578-x) 发布的 [AFT–MAG 数据记录](https://doi.org/10.5281/zenodo.4917086)，CC BY 4.0。下载器逐文件校验源站 MD5，仅获取研究者、关系和论文关联三张表。大文件不入 Git。

```bash
.venv/bin/python research/fetch_aft.py
.venv/bin/python research/aft_benchmark.py prepare --labs 40
.venv/bin/python research/aft_benchmark.py fetch-years
.venv/bin/python research/aft_benchmark.py repair-ids
.venv/bin/python research/aft_benchmark.py fetch-years
.venv/bin/python research/aft_benchmark.py evaluate
```

Key 由隐藏输入读取，只在进程内存中使用；年份请求逐批缓存，可续跑。评测报告写入 `research/aft-validation.json`，包括队列哈希、候选覆盖、Recall@1/2、MRR、合作次数基线、独立局部评分基线，以及按导师组重采样的差异区间。

评测目标是公开记录导师的检索，未标注关系不是负例。所有预选学生都进入总体分母；另报至少三个候选的较难子集。源数据的身份匹配部分使用了师生共著线索，而且候选范围限于抽取的 AFT 子网络，因此不能把结果包装为完整全球网络中的二分类准确率，也不能直接推广到计算机学科。报告不会抄用原论文的准确率。

### 2026-11-16 的实际验收结果

冻结队列为 40 个导师组的 120 名研究者。候选从 AFT 收录的共同作者中按合作次数取前 12 名，不把真实导师强行插入候选。对涉及的 688 人查询 98,019 个论文编号；按每人至少 95% 年份覆盖的门槛，最终保留 273 人。官方旧编号映射只用于补充缺口，当下 API 返回的原编号优先于历史合并记录，避免误合并已经恢复的实体。

| 同一候选池上的方法 | 全部 120 人 Recall@1 | Recall@2 | MRR |
| --- | ---: | ---: | ---: |
| 时序因子模型 | 16.67% | 19.17% | 0.1819 |
| 独立局部势函数 | 16.67% | 19.17% | 0.1819 |
| 合作次数基线 | 18.33% | 19.17% | 0.1892 |

只有 24/120 人的已知导师进入有效候选池。至少有三个候选且包含已知导师的子集仅 8 人，其首位命中率为模型 50%、基线 75%；不能把如此小的子集包装成总体性能。结果没有支持可靠身份识别，也没有显示联合模型相对简单基线的增益。已将该结论及数值打包到运行版本、页面和 JSON 导出中，并由后端关闭自动身份标签及其衍生关系，不仅是在页面增加一句提示。

`research/aft-validation-initial-rejected.json` 保留最初范围过窄的无效评测记录；正式可复算报告为 `research/aft-validation.json`，含队列、年份元数据与别名映射的哈希。测试后未按命中结果调参。本次实现通过数学和产品验收，**未通过可靠师生识别的统计验收**。候选谱系不能用作已确认关系或下游晋升模型的真实标签。

## 与其他关系的衔接

共同父节点得到同门候选；要称作同期课题组还需指导期和机构重合证据。跨代链需要各段时间一致。低指导分数保持未知，不自动改标为企业平台或同僚。预测边之间相关，模式分数不相乘成“同门概率”。

每篇论文的多人共同署名事件始终保留。候选谱系是叠加解释层，不会把原始论文拆成若干互相独立的树。
