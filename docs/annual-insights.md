# 个人年度统计

网页「年度统计」使用所有已完成采集的作者论文并集。每次导出包含采集作者列表、采集更新时间、输入哈希、计算版本、年份、滚动窗口、计数规则与排除数量。这个采样总体不等于一个领域或大学的完整产出。

## 年度面板

图按指定窗口 [year-window+1,year] 建立。每篇 n 人论文的边权为 1/(n-1)，保留单作者孤点；超过 200 人的论文只退出图计算，排除数量写入每行。发表数量、集合内引用和 h/i10 则累计至该年，引用事件的时间来自引用论文的发表年。今日累计引用不参与历史计算。

- 圈内 z：同社区内加权连接强度的标准分，零方差记 null。
- 参与系数：1−Σ社区(连接强度份额)²，无连接记 null。
- Burt constraint 与 weighted effective size：按加权无向图计算，分别描述关系冗余与有效非冗余规模。
- k-core、局部聚类系数使用无权图；PageRank 使用分数边权。
- 窗口新增伙伴与伙伴保留率比较相邻窗口中的观察邻居；另报首次出现在目标历史中的伙伴数，重返的旧伙伴不算首次合作。首个窗口没有窗口间比较对象。
- Louvain 每窗独立计算，seed=42；不以社区编号追踪群体。

数学参考：Guimerà & Amaral (2005)、Burt (2004)，具体原始链接见 research-foundation.md。论文引用与署名只能支持观察范围内的指标，不能证明指导、任职或升迁。

Burt 计算避免对每个二阶路径重复求归一化分母，与 NetworkX 独立实现对随机加权图逐点核对。当前实际缓存的十年面板由约 39.98 秒降至约 0.56 秒，数值一致；该测量不是百万节点性能结论。

## 已退出网页主流程的机构比较

网页与默认导出不再显示机构排名，默认接口也不再计算它。以下保留原方法记录；仅显式请求 `include_rankings=true` 时可通过接口访问。

独立实现公开公式，不复制 CSRankings 的代码/名单或 AllRankings 数据。

1. 完整计数：机构参与的论文每篇计 1。
2. 分数计数：每作者分得 1/n，再按该作者当篇论文的署名机构数均分。无机构者的份额不转移给其他人。
3. 跨领域几何平均：选定所有领域含零值，计算 exp(mean(log(1+count)))。
4. 年均作者当量：一个已知署名 person-year 按其当年论文和当篇机构拆分；按所选年份数取平均。每作者产出为分数产出除作者当量。
5. Excess：用含零产出的正作者规模机构拟合 Count 的 Poisson 工作均值的幂律拟合（分数计数使用准似然解释，不是假装整数 Poisson 观测），减去该规模的预期产出。β 无法识别或无有限极大值时显示状态，不捏造系数。

所有排名保留并列名次，导出含每篇论文的机构信用。来源过滤只改变产出、不改变同领域作者规模分母。领域当前使用 OpenAlex 主领域，不是 AllRankings 的参考文献主题份额；来源是用户选择的 source ID，不冒充审核过的 CSRankings 会议或 OSR 顶层场所。用这些公式得到的只是本机观察集合的比较，不能叫两站排名的精确复现。

原始方法：https://csrankings.org/faq.html 与 https://ar.clarelab.moe/en/about/。

## 运行与验证

接口：`GET /api/insights/{author_id}?start=2016&end=2025&window=5`；可选 fields、sources 为逗号分隔的已观察 ID。网页支持领域、来源筛选、五种指标排序以及完整 JSON 导出。

测试独立核对分配守恒、领域零值、幂律参数、不可识别状态、未来信息隔离、引用时间与结构洞公式。真实浏览器检查另行执行。Python 3.12 的运行依赖锁定在 requirements.lock，包含包哈希。
