# 搜索分页与灰绿视觉系统

## 作者搜索

`GET /api/authors?q=…&cursor=…` 使用 OpenAlex 游标分页，每页 12 位。首屏传 `*`，下一页原样传回 `meta.next_cursor`；游标经 URL 参数编码。保留 `meta.count`，界面显示当前范围、总数和前后页按钮。ORCID / OpenAlex ID 精确查询始终只有一个终止页。

前端只保存本次查询的游标历史和当前页卡片，不为翻页采集论文。新查询重置游标；输入改变、打开档案时取消未完成请求，并用请求代数隔离过期响应。翻页失败保留当前页并允许重试；最后一页依据总数或空游标禁用下一页。返回搜索保留当前页。

来源：[OpenAlex 分页文档](https://help.openalex.org/api/paging/)，2026-11-16 核对。后续游标页需要 API Key；服务仍只在内存保存 Key。分页修复扩大可浏览候选范围，并不解决源数据库中的姓名拼写、合并或消歧问题。

## Shader 与配色

参考 [Azkun/balatroShader 的公开实现说明](https://github.com/Azkun/balatroShader)：在 GPU 中旋转和反复变换坐标，实时生成背景。项目使用独立编写的 GLSL，没有引入其库或复制游戏着色器、图片素材。

两次实际 WebGL 绘制：第一遍把径向旋转、四层值噪声及两级坐标扰动合成为雾场，写入离屏纹理；第二遍采样雾场，叠加独立颗粒与暗角。颜色由炭灰、低饱和雾绿和中性浅灰混合，CSS 再添加轻微纵向遮罩，保证搜索框清晰。

最高 30 帧/秒；显示分辨率长边不超过 1280，设备像素比上限 1.5，雾场分辨率为显示画布的 60%。进入档案、打开弹窗、隐藏页面时停止动画；用户可手动暂停，尊重系统减少动态效果设置。不支持 WebGL、创建失败或丢失上下文时使用双层 CSS 动态雾层，同样支持手动暂停、减少动态效果、隐藏页面和弹窗停帧；上下文恢复后重建资源。动画偏好仅在本次页面内存中保存。

全站共享 CSS 颜色变量。档案、筛选、表格、弹窗、网络和团队图采用静态浅灰绿色面板。分类节点使用低饱和但可区分的色板；新人/已有经验/未知仍有不同颜色。实线/虚线与说明同步更新。SVG 导出内嵌解析后的样式和背景，独立打开时保留文字对比度。

## 验证

- `tests/test_author_pagination.py`：游标编码与转发、总数、首屏、非法游标、精确查询终止页。
- `tests/browser_search_pagination.py`：真实浏览器前后翻页、末页、失败重试、查询重置、慢响应隔离、打开档案与返回。
- `tests/browser_landing_shader.py`：Chrome 实际编译并运行两个 Shader pass，检查暂停/恢复、档案与弹窗停帧、尺寸上限、手机布局、上下文恢复、减少动态效果和无 WebGL 降级。
- 原有 `browser_simple_ui.py`、`browser_group_completion.py` 验证搜索/档案/团队主流程；`browser_edges.py` 检查筛选、边说明、论文证据和独立 SVG 导出。
- 本机真实 OpenAlex 查询 `Chao Huang`：当次共 1,662 位候选，前两页各 12 位，作者 ID 无重叠。候选总数会随上游数据变化。
- 桌面与手机截图已人工检查。浏览器 Shader 自动化使用 SwiftShader 验证兼容性，不将其帧率作为真实显卡性能基准。
