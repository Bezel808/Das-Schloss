- 运行 `.venv/bin/python -m unittest discover -s tests -q`：35 项通过，Python 3.12.11，约 0.278 秒；测试隔离数据库，未改线上数据库。
- 只读 HTTP 检查：服务可达；settings 仅返回 `key_configured`；缓存有 17 个作者任务。两个 report 请求分别返回 173 篇/304 节点/1223 边和 1337 篇/359 节点/1107 边，响应体 4,592,936 与 12,207,184 字节，用时约 0.210 与 0.587 秒。这是单次本地观测，不是吞吐或 p95 基准。

## 优点

1. 论文事件与推断关系分开；年精度、不连续合作及原始日期冲突有显式表示。历史截止年同时限制候选池和特征计算。
2. 断点采集按页写事务；截断署名尝试补全；密钥不出现在公开 settings；本地 origin/host 限制存在。未发现需要为了本轮研究先转成公网服务的理由。
3. TPFG 条件最优值由独立穷举测试核对；求解超时不伪装最优；固定分母和失败评测保留。真实验收失败时关闭身份标签，比叠加假精度更可信。

## 必须修复的问题（按影响排序）

### P0：研究对象与图边界尚未形成可用的数据契约

`report()` 仍只用目标作者署名论文投影，而不是研究者完整邻域的诱导图；`decorate_graph()` 去掉中心点后求 Louvain。该边界适合描述其共同发表团队，但缺失合作者在其他地方的边。把这里的中心性、Burt constraint 或跨社区比例直接解释成全领域地位会系统偏误。当前没有统一的作者—年份面板、年度图索引、机会结果表及对应的覆盖字段。

**验收**：明确至少个人论文视图与扩展语料图两个作用域；面板每行保存作者、年、窗口、语料哈希、候选规则、特征版本和覆盖。同一统计值必须可回溯到输入论文集合，未来论文加入后不得改变既定截止年的候选和特征。不同边界的量不能静默放进同一个排名。

### P0：ranking、经典图任务与可验证预测尚未形成端到端实验

没有机构 ranking 计算、排名敏感性分析或可复现的未来边预测评测。补齐度、PageRank、k-core、社区角色、constraint 可以形成描述层，但这些是成熟算法，单独集成不是 KDD 新方法。结构洞的定义也不能从网络名词推导出“已经撮合了别人”。[NetworkX constraint 定义与权重约定](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.structuralholes.constraint.html)

**验收**：先确定一个预测任务，例如截至 t 已出现作者之间未来 H 年首次合作；风险集排除已有边，固定未发生事件的抽样概率。实现共同邻居、Adamic–Adar、Resource Allocation、Jaccard、preferential attachment 等可比较基线，再检验轻量学习器是否有留出时间上的增益。时间划分、未来结果构造、PR 指标、top-k 检索和校准分开报告，不能只给平衡采样上的 accuracy。ranking 则需明确论文计数/作者分数计数、领域与机构映射，验证参考规则一致性，再比较规则变化造成的名次波动。

### P0：当前真实实验不能支持主要研究主张

AFT 报告对工程诚实性有价值，但有效导师候选仅覆盖 20% 目标，模型无基线增益，不能支持师生预测贡献。缺失真实教育/任职结果也不能靠网络中心性制造晋升标签。测试通过与原论文方法实现都不能弥补这一缺口。

**验收**：冻结下一轮训练/验证/测试方案；保存所有失败与排除分母；报告覆盖与模型增益的分解。需要至少一种可直接观察、可跨时间验证的结果，以及独立时间/领域上的稳定性检查。新贡献可以是边界缺失下的排名/预测稳健性方法，但必须有新方法或新实证，不能只是风险说明。

### P1：环境声明和复现不足

`pyproject.toml` 声明 Python >=3.9，`server.py` 使用没有 postponed annotations 的 `int | None`，其类型联合语义是 Python 3.10 新增；当前声明与实现不一致。[Python 3.10 官方变更](https://docs.python.org/3.10/whatsnew/3.10.html) `run.sh` 每次启动重新安装区间依赖，无锁文件；当前真实元数据只在被忽略的本地缓存中，输入哈希有助核对，但其他机器无法只凭哈希取回同一内容。

**验收**：修正最低 Python 版本；锁定依赖和解释器说明；在干净环境安装、离线重跑冻结小型真实实验。发布可分发输入或可恢复同一快照的 manifest，记录许可、版本、原始文件校验和、代码版本和完整命令。应能比较指标及逐例输出，而不只检验文件存在。

### P1：小数据交互可用，规模扩展尚无证据

每次 report 加载全部作者论文、重建投影、跑社区、把原始论文连同所有边事件一起返回。当前 1337 篇已经返回约 12 MB；时间回放会重复此流程。投影成本为 Σ binomial(作者数,2)，200 人论文阈值降低单事件开销，但没有总事件/边预算或规模曲线。TPFG 为每个候选状态重复求 MILP；最优性控制良好，但没有随候选/分量规模增长的测量。

**验收**：图/面板响应与论文分页分离，按语料版本和窗口缓存，导出仍保留完整证据。测量 10³、10⁴、10⁵ 论文或现实可取得的等价规模下的用时、峰值 RSS、响应大小与求解超时率，说明复杂度及截断策略。若实际遇到硬件上限，记录可重现的失败、峰值资源及稀疏/分块替代方案；不能用未经测量的“大数据”作为停止理由。
