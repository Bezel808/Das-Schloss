## 审阅范围和已确认的改进

读取 `docs/budgeted-acquisition.md`、`scholartrace/acquisition.py`、`research/temporal_benchmark.py`、`scholartrace/ranking.py`、`scholartrace/analytics.py`，以及两个 `research/results/*2008-n128-s42-author-query-cn-2.json`。这是对所读版本的审稿；后续代码修复需通过复评确认。

- `cohort()` 仅按历史活跃度、历史邻居和固定哈希抽样，没有按未来有无正例筛选目标。
- 预算 0/5/10/20/40 都保持 128 个目标，前沿耗尽者保留状态，避免此前大预算分母变化。
- 策略只接收 `Observation`；未来集合由评价器独立读取。查看调用链未发现未来标签传给查询策略或分数计算。完整数据索引虽包含未来作者，但策略的可查询 ID 来自已观察历史事件，因此这点本身不构成泄漏。
- 新合作、重复合作与冷启动分开定义；未被发现的新合作正例仍进入 Recall 分母。没有使用随意平衡非边样本的 accuracy。
- `certificate()` 明确证明历史 CN 排名，不把它解释成未来合作保证。区间宽度取决于未查询关系，避免把未知边当已知不存在。
- 年度面板的被引量、h-index、i10-index仅由语料内带年份引用计算，命名注明 within_corpus；不把今天的累计引用贴回历史。
- 重复合作分数由首轮完整目标作者查询已确定，理论上不应随后续预算变化，可作为管道负控制。

## 必须修正或明确的测量问题

### P0：滚动窗口新增不是首次合作

`analytics.annual_panel()` 的 `new_neighbors` 是本窗口邻居减去上一窗口邻居。一个老合作者缺席多年后重返窗口，也会被计为新邻居。建议保留该量但改为 `window_added_neighbors`，另用截至上一年的全部历史邻居计算 `first_time_collaborators`。两者在 UI、导出、预测标签中不可混用。

### P0：ORCID 可选字段不能直接替代稳定作者主键

`ranking.compare_rankings()` 用 `entry.author.orcid or entry.author.id` 分组作者—年份。如果同一人的某篇署名附有 ORCID、另一篇只有 OpenAlex ID，会被拆成两个作者—年份，导致作者当量和规模调整失真。固定使用源作者 ID，或先构建经过一致性检查的完整映射；仅字符串 fallback 不是消歧。需要加入混合 ORCID 缺失、冲突映射、变体前缀的测试。

### P1：预算的单位与真实查询代价

当前预算是完整作者查询次数。一次查询可能返回几十或上千篇论文，不能把它直接等同相同 API 请求数、传输量或运行时间。例如 DBLP 预算40下，observed_degree 平均观察1650篇，random平均947篇，ambiguity_cover平均1353篇。

这是合法的单位成本作者 oracle 设定，须明确命名；若主张现实采集效率，增加按返回论文数、去重论文数及100条/页的请求量衡量的成本曲线。在未查询前未知响应大小时，只能使用历史可见信息估计代价；不能事后以真实代价为先验挑选查询。给出预算最后一次响应越界的处理规则。

### P1：规模调整是观测语料模型，不是机构效率估计

当前论文分数为分数计数，`size_adjusted()` 标为 Poisson MLE。分数计数不是整数 Poisson 观测；可将其表述为 Poisson形式的准似然/均值拟合，但不能在没有额外假设时直接使用 Poisson分布的显著性检验或置信区间。规模与产出还由同一论文子样本构造，残差“excess”不是因果效率。

`per_author` 是窗口总产出除以窗口平均年度作者当量；改变窗口长度时不应直接当成相同单位的年度生产率。建议另给 `annual_fractional_papers_per_author = count / window_years / mean_annual_authors`，并保留原始累计值清楚标单位。

主领域归属、当前 OpenAlex 主题、来源筛选与机构署名均是观测定义，不等价于 CSRankings 教师名单或 AllRankings 的完整方法；当前文档明确区别值得保留。历史引用截断不意味着得到历史版本快照，当前重分类/撤稿字段依然可能回写过去，需记录来源获取日期。

## 查询机制与统计协议的补充验收

1. **证书检查补齐未发现候选。** 当前真实评价器核查所有已发现候选的界和最终证书，应额外断言：完整历史中所有尚未发现的候选 CN 均不超过 `unseen_candidate_upper`。理论式正确仍需要管道检查其信息条件。
2. **查询返回的一致性。** `reveal()` 对新增事件与已完成查询的矛盾作了拒绝，良好；同一 event_id 若被返回为不同作者集合/年份，目前仅按 ID 去重会忽略冲突。完整查询证书应保存事件摘要并拒绝此类矛盾。该问题是证书前提的工程实现，不必把现实源的每个脏数据假设成模型错误。
3. **重复边负控制。** 同一作者、同一预测起点的三种重复合作分数与结果应在全部查询策略/预算一致，作为自动验收。
4. **目标定义。** 现有抽样总体是过去5年≥3篇且历史≥2邻居的作者，结论仅针对该总体。冷启动新伙伴已经单列，但未来才进入的目标作者本身不在任务中；需清楚保留这一区别。
5. **并列分数。** 固定 ID 排序可复现但不具有科学含义，尤其EdgeBank在新边任务全部为0。补充并列随机化/期望命中敏感性；不要把ID运气作为算法优势。当前无信息基线仍保留是好做法。
6. **候选集合差异。** 不同策略发现不同候选，既应报告端到端结果，也应在同一已发现集合上比较不同分数器；共同集合仅用于诊断，不能取代主任务完整分母。

## 下一阶段 ML：先验证增量而非堆复杂模型

建议先实现正则化 logistic 与一个浅层树模型，训练对象为过去起点的 `(focal, candidate, cutoff, query_policy, budget)`，预测下一年首次合著。特征包括观测 CN/AA/RA、历史活动量、最近共同邻居事件、目标和候选查询完成状态、CN区间宽度、发现轮次。未查询的候选总产出/度数必须保留缺失或上下界，不能取评价器完整图值填充。

- 使用早期起点训练、中间起点选特征/参数，冻结后才开放后期验证和最终测试；同一年按期初历史生成全部特征。开发2008预测2009已被查看，不应再冒充封存测试。
- 模型只在同一预算下产生的观察样本上训练。若将多预算样本合并，按作者—起点分组防止同一正例重复放大；最终每个预算仍用固定目标分母。
- 将“更好查询策略”和“更好评分器”拆成2×2消融：固定查询比较模型、固定评分比较策略，并报告二者组合。不能用额外的查询或更大候选集解释为模型本身增益。
- 如需采样非边，记录采样概率和源候选分布；排名可以直接评估，概率校准必须恢复现实基率。未发现候选作为召回损失保留，不伪造其已观察特征。
- 对每作者输出Top-k并同时提供拒绝输出机制；阈值在验证段确定。全样本都推荐十人虽能计算P@10，却不等于适合实际用户。
- 不要求神经网络才能有贡献；需要至少一个强、调参预算对等的经典学习基线，以及最近时序图/主动查询方法的适配比较。是否加入复杂模型应由研究问题和开发集证据决定。

## 可靠区间与泛化：明确要对什么总体推断

**有限固定图的抽样不确定性：** 若研究目标仅是冻结图中满足历史条件的作者总体，哈希随机抽目标近似随机抽样，可采用配对按目标重采样，必要时加有限总体修正。即使作者共享图，条件于固定总体的设计型抽样推断仍可能成立，不能泛泛声称“有网络依赖所以所有作者bootstrap都无效”。但要记录抽样总体规模、抽取规则和抽样比例。

每次bootstrap应在同一重采样目标上重算两个策略的 **sum(hits)/sum(gold)** 后取差，不能分别bootstrap再相减，也不能把个体Recall均值冒充micro recall。无正例的目标仍在P@10分母中。History零正例bootstrap replicate要记录并处理，不能静默除零或删除后给过窄区间。

**未来年份和新领域泛化：** 上述区间只反映一个冻结图上的目标抽样，不能代表跨年份、数据源或领域稳定性。增加多个滚动起点，报告逐起点配对差及时间块不确定性；当前一个2008起点无法估计时间异质性。2个领域也不足以估计“随机领域总体”的方差，应逐域呈现。

**策略随机性：** random policy需要多个随机种子，最好预先固定相同目标队列。种子变化回答查询随机性，队列变化回答抽样变化，两者分开报告。128目标×5预算×多个策略不是新的独立样本量。

**少数事件：** History每种策略仅2次命中时，区间和比较功效非常有限。必须保留整数命中、正例26、正例目标15以及零命中目标比例；不能靠增加bootstrap次数制造证据。扩大历史抽样总体或增加预先确定的预测年份，比把种子重复次数当独立事件更有意义。
