# 并列敏感性与多年份开发扩展

在此批结果运行前固定：DBLP 截止年 2000、2002、2004、2006、2008；MAG-History 截止年 2004、2006、2008；每个域/年份 512 名目标，seed=42，沿用历史活动筛选、七种查询策略和 0/5/10/20/40 预算。年份以原有 2000–2008 开发区间均匀取点；History 使用三点作外域开发检查。全量发布，不按结果挑选年份。2009–2010 验证与 2011–2013 最终留出仍不解锁。

主指标改为分数相同的候选在块内均匀排列时，前十命中数、recall 和 AP 的精确期望。使用 McSherry & Najork (ECIR 2008) 的并列积分原则，独立实现二元相关性公式；不是新算法贡献。参考：https://marc.najork.org/papers/ecir2008.pdf 。score 相等按浮点精确相等定义，不事后调 epsilon。未来已见人物的全部新合作是 recall/AP 分母，未进入候选池仍计失败；无正例目标的 recall/AP 未定义，precision 分母固定 10。

每个并列块有 m 个候选、r 个正例；之前有 n 个候选、a 个正例。块内第 j 位对未归一化 AP 的期望贡献为 [(a+1)r/m + (j−1)r(r−1)/(m(m−1))]/(n+j)，m=1 时第二项为零。前十命中期望贡献为 r×clip(10−n,0,m)/m。用小规模全部排列与全部标签组合验证公式；模拟验证仅证明计算正确，不证明真实预测有效。

输出保留原 ID 决胜指标为审计，并新增 tie_expected、边界并列比例，以及所有并列排列下命中数的最小/最大值。最小/最大值是排列敏感性范围，不是置信区间。指标版本独立纳入 run ID、实现哈希和导出，不覆盖旧报告。

每个域/年份分别报告目标数、正例目标数、gold 总量、候选覆盖、冷启动占比、完整历史 CN 参考、重复合作基线和实际获取成本。跨年概括以每年 recall 的等权平均为描述统计，附逐年值，不把五个年份或多预算当作大量独立重复。按目标配对的 bootstrap 只表达固定源图与规定抽样下的条件不确定性；不当作跨年份泛化或两种策略等效证明。

完整历史 CN 参考仅枚举至少共享一名邻居的候选；因此是两跳候选规则下的参考，不是所有历史人物的最优预测上限。期望命中可能为小数；不得四舍五入后冒充实际整数命中。

## 源数据修订（第一批中止后、重新运行前固定）

2000 年开发运行在第 245 位目标触发源事件内重复作者校验，中止并保留前 244 位记录。新版本 `unique-incidence-1` 对每篇论文保留每个作者 ID 的第一次出现；不删除事件、不合并作者 ID、不合并相同作者集合的不同论文、不改年份。所有作者索引、活动量筛选和查询使用同一规范化数组。原始压缩文件与数组保持原样；运行记录保存源哈希、预处理实现哈希、受影响事件数、移除署名数与位置哈希。新 run ID 重新冻结队列并从头运行，不续用旧的 244 位目标。

主要比较固定为歧义覆盖对仅历史合作者按度查询，预算 20；其他预算、策略、评分器作完整敏感性报告。逐域逐年给配对目标区间；不把跨域或跨年平均宣称为对未来年份的区间。所谓 gold 新边数实际为“目标—新合作者关联数”，两个目标都被抽中时可能对同一无向边计两次。完整历史 CN 排名恢复的 ID 决胜值仅供审计。
